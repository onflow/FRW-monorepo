# ✨ Novos recursos

- **COA → EOA Migração (Flow EVM):** Flow Wallet agora suporta a transferência de ativos da sua **Cadence Owned Account (COA)** para um endereço **EOA** padrão no **Flow EVM**. Isso ajuda a evitar problemas causados pelo fato de sua COA existir apenas no Flow EVM enquanto outras redes EVM não a suportam.
- **Rotação de chave Blocto:** Para usuários que estão migrando do Blocto para o Flow Wallet, adicionamos suporte para rotacionar chaves Blocto antigas para uma experiência mais segura e confiável.

🐛 Correções de bugs

- Animações mais suaves e atualizações de desempenho.
- A rotação de chave agora remove chaves revogadas após uma nova chave ser gerada.
