# ✨ 新功能

- **COA → EOA 迁移 (Flow EVM):** Flow Wallet 现在支持将资产从您的 **Cadence Owned Account (COA)** 迁移到 **Flow EVM** 上的标准 **EOA** 地址。这有助于防止因您的 COA 仅存在于 Flow EVM 而其他 EVM 网络不支持它而导致的问题。
- **Blocto 密钥轮换:** 对于从 Blocto 迁移到 Flow Wallet 的用户，我们添加了对轮换旧 Blocto 密钥的支持，以获得更安全、更可靠的体验。

🐛 Bug 修复

- 更流畅的动画和性能更新。
- 密钥轮换现在会在生成新密钥后移除已撤销的密钥。
