# ✨ 새로운 기능

- **COA → EOA 마이그레이션 (Flow EVM):** Flow Wallet이 이제 **Cadence Owned Account (COA)** 에서 **Flow EVM** 의 표준 **EOA** 주소로 자산을 이동하는 것을 지원합니다. 이는 COA가 Flow EVM에만 존재하고 다른 EVM 네트워크에서는 지원되지 않아 발생하는 문제를 방지하는 데 도움이 됩니다.
- **Blocto 키 순환:** Blocto에서 Flow Wallet으로 마이그레이션하는 사용자를 위해, 더 안전하고 신뢰성 높은 경험을 위해 이전 Blocto 키를 순환하는 기능을 추가했습니다.

🐛 버그 수정

- 더 부드러운 애니메이션 및 성능 업데이트.
- 키 순환은 새 키가 생성된 후 취소된 키를 제거합니다.
