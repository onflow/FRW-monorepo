✨ Neue Funktionen

- **COA → EOA Migration (Flow EVM):** Flow Wallet unterstützt jetzt die Übertragung von Vermögenswerten von Ihrem **Cadence Owned Account (COA)** zu einer standard **EOA** Adresse auf **Flow EVM**. Dies hilft Probleme zu vermeiden, die dadurch entstehen, dass Ihr COA nur auf Flow EVM existiert, während andere EVM-Netzwerke es nicht unterstützen.
- **Blocto-Schlüsselrotation:** Für Benutzer, die von Blocto zu Flow Wallet migrieren, haben wir Unterstützung für die Rotation alter Blocto-Schlüssel für eine sicherere, zuverlässigere Erfahrung hinzugefügt.

🐛 Fehlerbehebungen

- Flüssigere Animationen und Leistungsupdates.
- Die Schlüsselrotation entfernt jetzt widerrufene Schlüssel, nachdem ein neuer Schlüssel generiert wurde.
