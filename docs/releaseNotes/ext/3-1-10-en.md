✨ New Features

- **COA → EOA Migration (Flow EVM):** Flow Wallet now supports moving assets from your **Cadence Owned
  Account (COA)** to a standard **EOA** address on **Flow EVM**. This helps
  prevent issues caused by your COA existing only on Flow EVM while
  other EVM networks don’t support it.
- **Blocto Key Rotation:** For users who migrating from Blocto to Flow Wallet, we added support for rotating old Blocto keys for a safer, more
  reliable experience.

🐛 Bug Fixes

- Smoother animations and performance updates.
- Key rotation now removes revoked keys after a new key is generated.
