✨ New Features

- **COA → EOA Migration (Flow EVM):** Move assets from your **Cadence Owned
  Account (COA)** to a standard **EOA** address on **Flow EVM**. This helps
  prevent `missing assets` issues caused by COA existing only on Flow EVM while
  other EVM networks don’t support it.
- **Blocto Key Rotation:** Added support to rotate Blocto keys for a safer, more
  reliable experience.

🐛 Bug Fixes

- Smoother animations and performance updates.
- Key rotation now removes revoked keys after a new key is generated.
