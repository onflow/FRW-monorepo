# ✨ Nuevas funciones

- **COA → EOA Migración (Flow EVM):** Flow Wallet ahora soporta mover activos desde tu **Cadence Owned Account (COA)** a una dirección **EOA** estándar en **Flow EVM**. Esto ayuda a prevenir problemas causados por tu COA existiendo solo en Flow EVM mientras otras redes EVM no la soportan.
- **Rotación de clave de Blocto:** Para usuarios que migran de Blocto a Flow Wallet, agregamos soporte para rotar claves antiguas de Blocto para una experiencia más segura y confiable.

🐛 Correcciones de errores

- Animaciones más fluidas y actualizaciones de rendimiento.
- La rotación de claves ahora elimina las claves revocadas después de generar una nueva clave.
